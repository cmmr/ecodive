# Authors and Citation

## Authors

- **Daniel P. Smith**. Author, maintainer.
  [](https://orcid.org/0000-0002-2479-2044)

- **Melissa O'Neill**. Contributor, copyright holder.  
  PCG random number generator

- **The scikit-learn developers**. Contributor, copyright holder.  
  SMACOF (MDS, NMDS), t-SNE, Isomap, PLS-DA and LDA code ported from
  scikit-learn

- **James Melville**. Copyright holder.  
  uwot's C++ header library, followed by the UMAP code

- **scikit-bio development team**. Contributor, copyright holder.  
  phylogenetic tree pruning and node numbering (rpca_phylo()), PCoA
  biplot scores, BIOENV, the alr and ilr transforms and balances,
  multiplicative zero replacement, the variance of log ratios, ANCOM,
  ANCOM-BC and ANCOM-BC2, Dirichlet-multinomial t-tests, and alpha
  diversity metrics (evenness, coverage, Hill numbers, Renyi and Tsallis
  entropies, dominance, the Gini index, and the bias-corrected Chao1),
  from scikit-bio

- **NumPy Developers**. Copyright holder.  
  numpy's pairwise summation, followed by replace_zeros_mult()

- **Cameron Martino**. Contributor, copyright holder.  
  'gemelli' robust Aitchison PCA and phylogenetic robust Aitchison PCA

- **Daniel McDonald**. Contributor, copyright holder.  
  tree shearing and collapsing, following 'iow' (bp)

- **The SciPy developers**. Contributor, copyright holder.  
  Procrustes analysis and a Nelder-Mead minimiser, following SciPy

- **Nathan Lemoine**. Contributor, copyright holder.  
  SIMPER, following 'ecopy'

- **Wright State University**. Contributor, copyright holder.  
  OPLS-DA, from 'pyopls'

- **Raes Lab**. Contributor, copyright holder.  
  quantitative microbiome profiling, following 'QMP.R'

- **Huang Lin**. Contributor, copyright holder.  
  ANCOM-BC and ANCOM-BC2 ('ANCOMBC'), via scikit-bio's port

- **ALDEx3 authors**. Contributor, copyright holder.  
  the scale model and effect sizes of dirmult_ttest(), following
  'ALDEx3'

- **Biota Technology**. Contributor, copyright holder.
